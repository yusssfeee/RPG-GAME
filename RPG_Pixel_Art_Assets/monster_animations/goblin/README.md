# Goblin Family

Approved character set: Goblin, Goblin Warrior, Goblin Archer, Goblin Chief.

Generated concept sheets are available in this conversation. They show the intended Idle, Walk, Attack, Hurt, and Death actions, but they are not yet clean production sprite atlases: frame cells vary in size and alignment, and some previews use a painted dark background rather than true alpha transparency.

Before integration, redraw/export each frame as an individual transparent PNG, standardize per-character frame dimensions and pivots, and verify loop timing. Keep the approved reference design: green skin, pointed ears, red accents, rough leather/metal armor, archer hood and bow, and chief's crown, fur, cape, and mace.
